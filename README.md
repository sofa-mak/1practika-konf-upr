# "Эмулятор командной строки UNIX"

Ссылка на репозиторий: https://github.com/sofa-mak/1practika-konf-upr/commits/main/r

## Описание

Эмулятор оболочки UNIX с графическим интерфейсом на языке Python.
Программа имитирует работу командной строки: принимает команды, разбирает их
на команду и аргументы, выполняет и выводит результат в окно.

Работает с виртуальной файловой системой (VFS), которая загружается из
JSON-файла и хранится только в памяти. Реальные файлы на компьютере не
изменяются.

## Как запустить

Требуется Python 3.

python3 main.py

Или с параметрами:

python3 main.py --vfs vfs.json --script start.txt

### Параметры командной строки

- --vfs — путь к файлу виртуальной файловой системы (по умолчанию vfs.json).
- --script — путь к стартовому скрипту, команды из которого выполняются
  автоматически при запуске.

## Поддерживаемые команды

- ls — показать список файлов и папок в текущей директории
- cd <папка> — перейти в указанную папку
- cd .. — перейти на уровень выше
- cd — вернуться в корень
- tail <файл> — показать последние строки файла
- tac <файл> — показать содержимое файла в обратном порядке
- touch <файл> — создать новый пустой файл
- rm <файл> — удалить файл
- clear — очистить экран
- exit — закрыть программу

## Структура виртуальной файловой системы

Файловая система описывается в JSON-файле и имеет три уровня вложенности:

/
├── motd.txt
└── home/
    └── user/
        ├── readme.txt
        └── documents/
            └── notes.txt

- / — корень.
- home/ — папка первого уровня.
- user/ — папка второго уровня.
- documents/ — папка третьего уровня.
- motd.txt — приветственное сообщение, показывается при запуске.

## Особенности

- VFS в памяти. Все изменения (touch, rm) происходят только в памяти.
  Файл vfs.json на диске не изменяется.
- MOTD. Если в корне VFS есть файл motd.txt, его содержимое выводится
  при запуске.
- Обработка ошибок. Программа сообщает об ошибках: файл VFS не найден,
  неверный формат JSON, неизвестная команда, файл не найден и т.д.
- Стартовый скрипт. Команды из файла выполняются последовательно;
  ошибочные строки пропускаются, выполнение продолжается.

## Файлы проекта

- main.py — основной код программы
- vfs.json — основная виртуальная файловая система
- vfs_minimal.json — минимальная VFS (один файл)
- vfs_files.json — VFS с несколькими файлами
- vfs_broken.json — пример повреждённого JSON (для теста ошибок)
- start.txt — стартовый скрипт для тестирования
- test_*.sh — скрипты для запуска эмулятора с разными параметрами
